# Domain Docs

Before exploring or changing the product, read root `CONTEXT.md` and every
relevant ADR under `docs/adr/`. Use the glossary's domain terms in issues,
tests, and documentation. Surface an ADR conflict explicitly; do not silently
override it.

This is a single-context repository. `CONTEXT.md` and `docs/adr/` are the
authoritative domain-document layout.
