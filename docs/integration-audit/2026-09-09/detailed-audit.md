## 4. P0: outbound dispatch can race and bypass later control changes

**Reproduced.** OutboxDispatchJob locks an event only to increment attempts, releases the lock while the event is still pending, then sends. Two workers can both pass the pending check. The harness reproduced two sender calls for the same event. Base channel sending checks whether a source_id already exists, but two concurrent attempts or provider acceptance followed by a local persistence failure can pass before that ID is recorded. This is a duplicate-attempt defect, not proof that Meta delivered a duplicate to a customer. [Dispatch race](</Users/ghalyasaid/.codex/worktrees/9b7a/AI Chatbot/docs/integration-audit/2026-09-09/evidence/source/app/jobs/ai_lead_employee/outbox_dispatch_job.rb:26>) · [Base sender guard](</Users/ghalyasaid/.codex/worktrees/9b7a/AI Chatbot/docs/integration-audit/2026-09-09/evidence/source/app/services/base/send_on_channel_service.rb:13>)

**Reproduced/static.** Final AI-control checks apply only when the outbox payload contains follow_up_id. Ordinary AI replies return true immediately. The harness dispatched an ordinary event while the conversation was human_active. IntentProcessor checks tenant, launch gate, version, assignment, opt-out, and human response before creating output, but human takeover after output creation leaves a completed intent’s queued message eligible for later dispatch. SendReplyJob does not independently enforce those AI conditions. [Follow-up-only final checks](</Users/ghalyasaid/.codex/worktrees/9b7a/AI Chatbot/docs/integration-audit/2026-09-09/evidence/source/app/jobs/ai_lead_employee/outbox_dispatch_job.rb:65>) · [Intent checks](</Users/ghalyasaid/.codex/worktrees/9b7a/AI Chatbot/docs/integration-audit/2026-09-09/evidence/source/app/services/ai_lead_employee/orchestration/intent_processor.rb:12>) · [Intent invalidation](</Users/ghalyasaid/.codex/worktrees/9b7a/AI Chatbot/docs/integration-audit/2026-09-09/evidence/source/app/services/conversations/control_service.rb:11>) · [Delivery entry point](</Users/ghalyasaid/.codex/worktrees/9b7a/AI Chatbot/docs/integration-audit/2026-09-09/evidence/source/app/jobs/send_reply_job.rb:18>)
