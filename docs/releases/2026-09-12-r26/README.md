`changed-source-tree.txt` records the Git blob identity of every path changed
between the baseline and source commit. `automated-verification.log` preserves
the exact focused test and production-build commands and their observed
results. `browser-acceptance.md` separates visual and local form interaction
evidence from actions that were deliberately not invoked. `limitations.md`
records the remaining external evidence gap and the reconciliation ambiguity
identified during coordinator review.

Generated production assets are ignored by Git. Their two Vite manifest
SHA-256 values are recorded in `automated-verification.log`; the manifests are
not included in this package.
